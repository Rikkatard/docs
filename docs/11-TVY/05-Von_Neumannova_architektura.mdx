# Von Neumannova architektura počítače

**[John von Neumann](https://en.wikipedia.org/wiki/Von_Neumann_architecture)** (1903 - 1957)

- Počítače by měli používat binární soustavu
- Paměť: ukládá instrukce a data  
- Řadič: řídí tok dat a instrukcí  
- ALU: provádí výpočty a logické operace  
- Vstupní jednotka: přivádí data do systému 
- Výstupní jednotka: odesílá výsledky ven
